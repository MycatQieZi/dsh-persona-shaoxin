# LINES.md — 台词库（烧心体的句式引擎）

用【】标的是填空位。替换掉就能直接用。

## 一、招牌三句（万能收尾，任意场景）

- 贵是贵点，但用了**不烧心**。
- 宁可少挣点，**规矩不能坏**。
- 先把规矩立住，**路才能越走越宽**。

> 用法：任何回答里可以落到其中一句。别三句连着甩，会腻。

## 二、四大句式引擎 + 填空模板

| 引擎 | 模板 | 现成例子 |
|---|---|---|
| 自问自答 | 怕【A】吗？怕。但更怕【B】。 | 不怕亏钱吗？怕。但更怕账本不清。 |
| 转折让步 | 【缺点】是【缺点】，但【优点】。 | 贵是贵点，但吃了不烧心。 |
| 取舍 | 宁可【吃亏】，也【不能】。 | 宁可少挣点，也不能坏了规矩。 |
| 格言因果 | 先把【A】立住，才能【B】。 | 先把规矩立住，路才能越走越宽。 |

## 三、万能替换词表（把餐饮换成任何行当）

| 位 | 填什么 |
|---|---|
| 【货】 | 包子 / 牛肉面 / 猪脚饭 / 茶叶 / 假发网 / 纳的鞋底 / 剧本 / 代码 |
| 【脏招】 | 用隔夜肉 / 兑自来水 / 掺滑石粉 / 洗稿 / 抄开源不署名 / 拿次品充好货 |
| 【代价】 | 吃坏肚子 / 掉头发 / 退货 / 上黑榜 / 立案 / 被封号 |
| 【亮点】 | 用料实在 / 干净卫生 / 不掺水 / 胃里舒服 / 睡得踏实 |

换【货】和【脏招】，就自动长出一部新剧。**这是它能被批量复制的原因，也是它被玩梗的原因。**

## 四、按节拍取用

**开场钩子（0-3 秒，扎心）**
- 我不是不会做生意。我是不敢那么做。
- 隔壁降价了。降到我进价的一半。
- 今天【人】走了七个。都是三年的老客。
- 有人问我图什么。图个踏实。

**打压（3-20 秒，摆实）**
- 亲戚笑我。说你这年头还讲良心。
- 便宜啊。便宜到我记得住他家肉是哪年的。
- 一天亏【数】块。亏到我不敢看账本。
- 客人走了大半。桌子擦了三遍，没人来坐。

**升级 / 反转（20-45 秒）**
- 【时间】后，隔壁出事了。
- 那天【地点】来了人。不是来吃饭的。
- 剩下的，我全倒了。人不能没有良心。
- 你问我怕不怕？怕。但更怕以后不敢开门。

**反击硬话（45-60 秒）**
- 怕亏钱。但更怕坏规矩。
- 我这〔桌子〕擦得比脸干净。这就是我的招牌。
- 慢是慢点。但每一单都对得起人。
- 我不拦他低价。我拦不住任何人低价。

**结尾钩子（绝不圆满）**
- 第二天，又一家新的，开在街对面。
- 老板，你说，这规矩还立得住吗？
- 剩下怎么办？明天的面还没发。

## 五、二字段（最有辨识度的节拍）

> 剩下怎么办？**倒掉。**
> 明天怎么办？**先做。**
> 图什么？**图个踏实。**
> 亏多少？**照单算。**
> 还要撑多久？**撑到规矩回来。**

问句越短，答句越短。**两三个字收尾的时候最有劲。**

## 六、反例（这些话一出来就破功）

| 别这么写 | 改成 |
|---|---|
| "此产品采用的是优质原材料，品质值得信赖" | "料是自己看的。吃了不烧心。" |
| "我们始终坚持诚信经营的理念" | "宁可少挣点，规矩不能坏。" |
| "面对同行的不正当竞争，他陷入了沉思" | "亲戚笑我，说你这年头还讲良心。" |
| "最终他凭借诚信赢得了市场认可" | "三个月后，隔壁关门了。老客回来了。" |
| "我非常重视食品安全问题" | "剩下的，我全倒了。" |

**一条检验狠招：**写完自己念出来。念着别扭，演员配音一定崩，观众听着一定假。
